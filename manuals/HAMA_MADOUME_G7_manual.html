01どんなEAか

窓は開けたら閉めましょう。
その戻りだけを、トレンドの方向に拾う。

勢いのある動きのあとには、ローソク足の間に価格が飛んだ「窓」（FVG：Fair Value Gap）が残ります。 XAUUSDのM5では、窓の約8割が1時間以内に端まで戻ってきます（2019〜2026年）。ただし窓埋めだけでは勝てないので、H1のトレンドの方向・割安／割高の側・構造の外の損切りで裏付けた窓埋めだけを狙います。 HAMA MADOUME G7 はM5の窓を自動で見つけ、H1のトレンドの方向で、窓埋めに戻ってきたところで入ります。

POINT 01窓（FVG）を自動で見つけるM5でATRの0.3倍以上の窓だけを拾い、チャートに「エントリー予定」として表示します。
POINT 02窓埋めの戻りで入る窓の端まで戻ってきたら成行で入ります。追いかけ買い・売りはしません。割高・割安も確認します。
POINT 03決まった幅で損切り、トレールで伸ばす損切りは建値から$15（初期値）。$30有利になったらトレールで伸ばします。トレンドが反転したら全部決済。

02売買の仕組み

  1. トレンド（H1）H1のスイング高値・安値（左右3本より高い・低い足）を見ます。H1の終値がスイング高値を上抜けたら上昇トレンド（買いだけ）、スイング安値を下抜けたら下降トレンド（売りだけ）です。反対側を抜けるまで続きます。
  2. 待つ場所（M5のFVG）トレンドの向きにM5でFVGができたら、その端（買いは上端、売りは下端）で待ちます。窓の幅がATR(14) ×0.3以上のものだけです。待つのは1時間で、届かなければ取り消します。
  3. 割安フィルター買いはH1のスイング高値と安値のちょうど中間より下、売りは中間より上で待つときだけ入ります。高いところでは買わず、安いところでは売りません。
  4. 入る待っている価格に届いたら成行で入ります。最大7本まで（初期値。EAの設定画面の「最大保有本数」で変えられます）。満杯になったら待っている注文は取り消します。
  5. 損切り1本ごとに、建値から$15（初期値。設定欄のTP / SLのRR方式の「SL幅 $」）。ブローカーにも置きます。
  6. 利確初期はトレールで伸ばします。建値から$30（損切り幅の2倍）有利になったら、今の価格から$22.5の所に損切りを付けて、価格に合わせて上げていきます。利確ラインは置きません（トレールOFFのときは、建値から$30で利確）。
  7. トレンド反転H1のトレンドが反対になったら、次のM5の足で残りを全部決済します。
  8. ロット1本ごとに「損切りに掛かったら 残高 × リスク% の損失」になるよう計算します（初期0.1%）。同じ向きで最大7本まで持つので、全部が損切りになると合計で最大7倍の損失になります。過去7年の検証では、一番大きい落ち込みが0.3%で約18%、0.1%で約6%でした。H1のADXが30未満（レンジ気味）なら半分。最小ロット未満になったら（スタンダード口座の少ない資金など）、最小ロットで入り、同時に持てる本数を減らします（09の「スタンダード口座で使うとき」）。ロットの元にする残高は、複利（初期）・単利・自動 攻め・自動 守りから選べます（06のLOT）。

サーバー時刻0〜1時台（日本時間6〜7時台、スプレッドが広がる時間）の足では、新しく待ちません。

03SMCとは（言葉の説明）

SMC（スマートマネーコンセプト）は、銀行やファンドなどの大口投資家（スマートマネー）の売買の跡を、チャートの「構造」から読み取ろうとする考え方です。 大口の注文は一度に約定しきれないため、相場には「勢いよく動いた跡（窓）」や「その動きが始まった場所（OB）」が残り、価格はそこへ戻ってきやすい、と考えます。 HAMA MADOUME G7 は、この考え方のうち、数字で決められる部分だけをルールにしています。

このEAが使うSMCの要素

要素意味このEAでの使い方
構造（スイング）相場の山（スイング高値）と谷（スイング安値）。左右3本より高い・低い足H1の流れ（BOS）と、割高・割安の中間を決める
BOS前の山を終値で上に抜けること（下降中は、前の谷を下に抜けること）。抜けた向きが、今の流れの向きですH1で、買いだけか売りだけかを決める
CHoCH今までと反対側を終値で抜けること。流れの向きが変わった合図です向きが変わったら、残りを全部決済
FVG（窓）勢いよく動いて、ローソク足の間に価格が飛んだ所M5で、窓埋めに戻ってきたところで入る
割高・割安前の山と谷のちょうど中間より上が割高、下が割安買いは割安側、売りは割高側でだけ入る
OB（オーダーブロック）窓を作った動きの直前にある、逆向きのローソク足。大口が注文を入れた場所と考える売買には使わない（インジケーターSMCで帯として表示）

SMCにはほかにも「流動性（多くの損切りが集まる価格）」などの考え方がありますが、このEAでは使っていません。

BOSBreak of StructureとCHoCHChange of Character

どちらも「前の山・谷を、ローソク足の終値で抜けたかどうか」で判断します。ヒゲだけで抜けたものは数えません。

  • BOS（流れが続く合図）：上昇中に、前の山を終値で上に抜けること。抜け続けている間は「上昇の流れ」です。下降中に前の谷を下に抜けるのもBOSです。
  • CHoCH（流れが変わる合図）：上昇中に、前の谷を終値で下に抜けること。上昇の流れが終わり、下降に変わったと考えます。下降中に前の山を上に抜けた場合も同じです。
  • このEAでは：H1（1時間足）で判定します。上昇の流れなら買いだけ、下降の流れなら売りだけを行い、CHoCHで向きが変わったら、持っているポジションを全部決済します。

FVGFair Value Gap＝窓

価格が勢いよく動いたときに、ローソク足とローソク足の間に残る「すき間」です。

  • 見つけ方：3本続いた足のうち、1本目の高値と3本目の安値の間が空いていれば、そこが窓です（下げのときは逆）。
  • 窓埋め：価格は、この窓を埋めに戻ってきやすい性質があります。XAUUSDのM5では、約8割が1時間以内、約9割が4時間以内に窓の端まで戻りました。
  • 注意：窓に戻ったあと、そのまま突き抜けることもよくあります。そのため窓埋めは「入るタイミング」にだけ使い、売買の向きはH1の流れで決めます。損切りは決まった幅（初期は建値から$15）です。
  • このEAでは：窓埋めで戻ってきたところでだけ入ります。

割高・割安プレミアム・ディスカウント

直近の山（スイング高値）と谷（スイング安値）の、ちょうど真ん中を境目にします。真ん中より上が割高、下が割安です。

  • 上昇の流れでは、割安側でだけ買います。
  • 下降の流れでは、割高側でだけ売ります。
  • 高い所で買ったり、安い所で売ったりしないための仕組みです。

OBオーダーブロック

窓（FVG）を作った大きな動きの、すぐ前にある逆向きのローソク足です。大口の投資家が注文を入れた場所と考えられ、価格が戻ってくると反応しやすいと言われます。

  • このEAでは：売買には使いません。インジケーター「SMC」で、価格が触れた回数と一緒に帯で表示できます。

ADXトレンドの強さ

トレンドの強さを0〜100で表す指標です。上げ・下げの向きは関係なく、一方向に強く動いているほど高くなります。

  • このEAでは：30未満は方向感のない相場（レンジ）と考え、ロットを半分にします（初期値。設定欄のADXで変えられます）。

04操作パネル

見出し（左側）をドラッグすると動かせます。右上の成績は日別の成績レポート（開いたときは、HAMA MADOUME G7だけを表示します。上のボタンで「すべて」やほかのEAに切り替えられます）、説明はこの説明書、設定はEAの設定画面（F7）を開きます。

  • 買いON / OFF・売りON / OFF：その向きの新規を止めます。保有中の損切り・利確・反転決済は続きます。
  • 建値ON / OFF：建値発動（後述）。
  • 買い全決済・売り全決済・全決済：確認のあと成行で決済します。トレンドが続いていれば、次のFVGからまた建てます。
  • 指標停止ON / OFF：重要な経済指標の前後は新しく建てません。
  • 待機中の注文を消す：今FVGで待っている注文を取り消します。
  • 途転／両建／建値復活ON・OFF：補助の機能（初期はOFF。説明は08）。
  • SMCの表示：FVG / OB / BOS/CHoCH / 中間／高安OB / エントリー枠のボタン（横3列×2行）で、SMCの帯や線（インジケーターSMC）と、紫のエントリー枠（このEA）を出したり消したりできます。ONのボタンはチャートの表示と同じ色（FVG = 緑、OB = 赤、BOS/CHoCH = 青、中間 = グレー、高安OB = 濃い青、エントリー枠 = 紫）、OFFはグレーです。チャートがごちゃごちゃするときは、見たいものだけONにしてください。売買には影響しません。

05P/Lパネル

現在損益・買い／売りの損益・本日損益・口座残高・本日最大含み損、今の状態、H1のトレンドとスイング高値・安値、ADXとロット倍率、方向ごとの本数・待機中の注文・全部損切りになった場合の損益、次の1本のロットとスプレッドを表示します。

「本日損益」の行の小さなリセットボタンを押すと、確認のあと、本日損益と本日最大含み損を0に戻して、そこから数え直します。ボタンには、リセットした時刻（例「12:34〜」）が出ます。表示だけのリセットで、売買や口座残高には関係ありません。その日のうちはMT5を再起動しても残り、日付が変わるといつもの数え方に戻ります。

06設定欄

値を変えて設定を反映を押すと使われます（押すまでは変わりません）。次に建てる1本から使い、保有中のポジションの損切り・利確は変えません。

「初期値に戻す」「設定を反映」の右のボタンです。押すと確認が2回出て、両方「はい」を押すと、パネルで変えた設定（各ボタンのON / OFF・ロット・利確損切り・トレール・両建・建値の幅・稼働時間など）をすべて初期値に戻します。戻した設定は保存され、MT5を再起動しても残ります。初期値は、このEAに書き込んである初期値です（EAの設定画面（F7）で値を変えていても、そちらは使いません）。検証で一番良かった設定になります。
「マイ設定を保存」「マイ設定を読む」「設定を反映」の下の行のボタンです。「マイ設定を保存」は、今使っている（反映済みの）設定を1つ保存します（前に保存したものは上書き）。「マイ設定を読む」は、確認が2回出て、両方「はい」を押すと保存した設定に戻します。初期値（一番良い設定）とは別に、自分の好きな設定を1つ持っておけます。

設定欄は2つに分かれていて、それぞれのボタンで開いたり、たたんだりできます（HAMA TREND G3と同じ）。たたんだ分だけパネルが短くなります。

  • 売買の設定：LOT・TP / SL・TRAIL・ADX・HEDGE・BE・DAY LIMIT。起動したときは開いています。
  • 稼働時間の設定：TIME（曜日・時間）。起動したときはたたんであります。

両方たたむと、設定を反映のボタンも隠れます。

  • LOT：リスク%（1本あたり）と固定ロット（0なら自動）。その下の4つのボタンで、ロットの元にする残高を選びます（NAMITOREと同じ。初期は複利）。
    ・複利（初期）：今の残高でロットを計算します。増えればロットも増え、減ればロットも減ります。
    ・単利：「はじめの残高」のままロットを計算します。増えても減ってもロットは同じです。
    ・自動 攻め：早く増やしたいとき。残高が「はじめの残高」の1段目（初期2倍）までは攻め（リスク%×2）、2段目（初期5倍）までは標準（リスク%）、その先は守り（リスク%×2/3）。どれも複利です。
    ・自動 守り：減らしにくくしたいとき。1段目までは単利の守り（リスク%×2/3）、2段目までは複利の標準、その先は複利の攻め（リスク%×2）。
    「はじめの残高」（0 = 使い始めたときの残高）と、1段目・2段目の倍率も変えられます。ボタンの下の行に、今の倍率・段階・実際のリスク%が出ます。切り替えたら設定を反映を押してください。どの方式でも、自動ロットの1本のリスクは「元の残高 × リスク% × 倍率」です。スタンダード口座の本数の調整（09）も、この実際のリスクで計算します。
    説明書の成績は、複利・リスク0.1%のものです。
  • TP / SL：3つの方式から選びます（TREND G3と同じ）。選んだ方式に●が付き、その方式の欄だけが表示されます。
    ・RR方式（初期）：1本ごとに、建値から「SL幅 $」で損切り（初期15）、利確 = SL幅×リワード÷リスク（初期1:2 = $30）。トレールONのときは利確ラインを置かず、トレールで伸ばします（Rは「SL幅 $」）。過去7年の検証で一番良かった形です。
    ・金額（円）：1本ごとに、損失が「SL 円」・利益が「TP 円」になる所に損切り・利確を置きます（TP 0 = 利確なし）。
    ・ドル（$）：1本ごとに、建値から「SL $」逆行で損切り（初期15）・「TP $」順行で利確（初期30。TP 0 = 利確なし）。
    どの方式も、自動ロットは「損切りまでの幅で 残高 × リスク%」の損失になるように決めます。
  • TRAIL：1本ごとのトレールです（初期はON）。トレールボタンでON / OFF。Rは、建てたときの損切り幅です。開始R（初期2）：建値からRの何倍有利になったら始めるか。幅R（初期1.5）：今の価格からRの何倍の所に損切りを付けるか。刻みR（初期0.1）：何R以上動かせるときに付け直すか。利確ラインも置く（初期OFF）：OFFなら利確ライン（2R）を置かず、トレールだけで伸ばします（変えたあとに建てた玉から）。
  • ADX：しきい値（初期30）と、その値未満のときのロット倍率（初期0.5）。
  • HEDGE：両建ONのときだけ使います。発動%（損切りまでの距離の何%逆行したら両建するか。初期75）、戻り%（両建した側の損切り = 元の距離×この%。初期50）、本数（保有がこの本数以上のときだけ。初期5）。
  • BE：建値発動の幅です。建値ONのときだけ使います。発動幅$（建値から何ドル有利になったら発動するか。初期2。0 = 即時）、建値+$（損切りを建値から何ドル有利な所へ移すか。初期1）。
  • DAY LIMIT：1日の損失上限です（初期はOFF）。日本時間9:00から数えて、その日の確定損益＋含み損益が−上限になったら止め、翌日9:00に再開します。1日の上限ON / OFF、上限に達したときの動き（全決済して停止か新規停止のみ）、上限$（1本のロットで、価格がこのドル数だけ動いたときの金額。初期80）、上限 円（0より大きければ円を使う。初期0）を決めます。止まっているあいだは、P/Lパネルの状態に「1日の損失上限で停止中」と出ます。
  • TIME (JST)：稼働する曜日と時間（日本時間）、時間外は全決済するか。

パネルの大きさ・文字サイズ

EAの設定画面（チャートのEAを右クリック→「プロパティ」→「パラメーターの入力」）の先頭、パネルの大きさ・文字サイズで変えます（HAMAと同じ）。

  • パネルの大きさ（%）：50〜250。操作パネル・損益パネルの両方が、この倍率で大きく・小さくなります（初期100）。
  • パネルの文字サイズ：6〜20（初期9）。文字を大きくすると、パネルも合わせて大きくなります。
  • パネルの位置X / Y：最初に出す位置。ヘッダーをドラッグして動かすと、そちらが優先されます。

画面の拡大率（Windowsの表示スケール150%など）にも自動で合わせます。設定欄を開くとパネルが縦に長くなるので、画面に入りきらないときは大きさを80%前後にするか、売買の設定・稼働時間の設定のボタンでたたんでください。

07チャートの表示

チャートには、EAが出す表示（紫の「エントリー予定」と、保有中の線）と、インジケーターSMCが出すSMCの帯（緑の窓・赤青のOB）が重なります。 紫 = EAがこれから入る場所、緑・赤・青の帯 = 相場のSMCの地図と覚えると見分けやすくなります。

EAの表示（紫 = これから入る場所、保有中の線）

①上部の案内EA今のトレンド（▲買い / ▼売り）と、買い・売りそれぞれ「次にどこで入るか」。まずここを見れば、今EAが何を待っているかが分かります。
②エントリー予定ゾーン（紫の枠）EA次に入る範囲。売りなら「中間〜スイング高値」、買いなら「中間〜スイング安値」。この枠の中に窓ができたら、その端で入ります。SMCの帯より前に出ます。
▶エントリー予定（紫の太線）EA窓ができて、実際に待っている注文。線の右に「▶ 売りエントリー予定 価格（ロット×1.0）」。1時間で消えます。
損切り予定（紫の点線）EA損切りは建値から決まるので線は出さず、枠の端に「損切り・利確：RR 方式 SL幅 $15 ・ RR 1:2（利確なし・トレール）」のように文字で出します。
保有中の建値・利確EA建値（青 = 買い／赤 = 売り）と、1本ごとの利確（緑の破線）。「#1 売り 建値 価格（今の損益）」のように表示。
保有中の損切り（赤橙の太い破線）EA方向ごとの損切りの位置と、そこで決済した場合の合計金額・本数。
両建ライン（オレンジ）EA両建ONのときだけ。ここまで逆行したら、反対側を同じロットで建てます。

インジケーターSMCの帯（相場のSMCの地図）

③ FVG（緑の帯）SMCまだ一度も触れていない窓。価格がここまで戻ってくると「窓埋め」。売りの構造なら上にある窓、買いの構造なら下にある窓が狙い目。
⑧埋まったFVG（グレー）SMCヒゲでも一度触れた窓。役目を終えたので、帯はそこで止まります。
OB（赤 = 上の売り側）SMC窓を作った動きの直前の足。価格が上がってくると反応しやすい場所。チャートの右端まで伸びます。
OB（青 = 下の買い側）SMC下がってきたときに反応しやすい場所。
⑤タッチ回数（だんだん薄く）SMCOBに価格が入るたびに1回と数え、濃い→薄いへ。何度も触れたOBは効き目が弱くなっている目安。終値で抜けたら消えます。
⑨最高値・最安値のOBSMC画面に見えている範囲の一番高い足・安い足。スクロールすると付け直します。
④中間（割高・割安の境目）SMCH1スイング高値と安値のまん中。上が割高（売り側）、下が割安（買い側）。
BOS / CHoCHSMC前の山・谷を終値で抜けた所。CHoCH（向きが変わった所）は白い太字で、価格と今の価格までのpipsを表示。

⬆買いのサインEA入った足の下に青い矢印（#1は大きく、#2以降は小さく）。
⬇売りのサインEA入った足の上に赤い矢印。

インジケーターSMCは、ナビゲーターの「インジケーター」にあるファイル（SMCHAMA_v1.11）を、同じチャートにドラッグして入れます。EAだけでも売買はできますが、帯があると「どの窓・どの OB の近くか」が目で分かります。EAのパネルの「表示の ON / OFF」ボタン（FVG / OB / BOS/CHoCH / 中間／高安OB / エントリー枠）で、帯や線を項目ごとに出したり消したりできます（インジケーターSMC v1.09以降）。

08建値発動・途転・両建・建値復活・指標停止・稼働時間

建値発動（1本ごと）

その1本の建値から$2有利に動いたら、その1本の損切りを建値+ $1に移します（プラスを確保）。金色の線はドラッグで動かせます。OFFにすると、建てたときの損切りに戻します。

発動幅と移す幅は、設定欄のBEで変えられます。発動幅を0にすると即時です。建値+ $1に損切りを置ける所まで来たら、待たずにすぐ移します。建値ONを押した時点ですでにその位置を越えているポジションは、その場で移ります。

トレール（1本ごと・初期はON）

建値から2R有利になったら、その1本の損切りを今の価格から1.5Rの所に付け、価格が伸びるたびに0.1Rごとに付け直します（Rは建てたときの損切り幅）。利確ライン（2R）を置かないので、トレンドが続くあいだ伸ばせます。チャートの金色の線は「トレール」と表示されます。

過去7年（2019〜2026年）の検証（最大7本・損切り$15・ADX<30・リスク0.1%）では、トレールなしの口座の増減+8.1%に対して、トレールONは+24.1%でした（一番大きい落ち込みは8.1% → 6.4%）。必ずそうなるわけではありません。

過去7年の年別（参考）

今の初期値（最大7本・損切り$15・ADX<30・トレールON・建値OFF・リスク0.1%）で、2019年11月〜2026年11月を検証した結果です。口座の増減は、リスク0.1%で運用した場合の目安です。過去の結果で、これからの成績を約束するものではありません。

1日の損失上限（初期はOFF）

日本時間9:00から数えて、その日の確定損益＋含み損益が−上限になったら、全部決済して（または新規だけ止めて）、翌日9:00まで新しく建てません。上限はドル（1本のロットで、価格がそのドル数だけ動いた金額）か円で決めます。円を0より大きくすると、円を使います。

過去7年の検証（今の初期値・最大7本・損切り$15・トレールON）では、上限$80で全決済して停止にすると、7年の増減が+24.1%から+24.7%（一番大きい落ち込み6.4% → 6.1%）、$50では+23.5%（5.5%）と、差は小さいものでした。そのため初期はOFFです。1日の負けを決めた額で止めたいときに使ってください。

途転・両建・建値復活（初期はOFF）

  • 途転：H1のトレンドが反転して保有を全決済したら、新しいトレンドの方向に成行で1本建てます（損切り・利確は今のTP / SLの方式。初期は建値から$15）。
  • 両建：保有が5本以上のとき、平均建値から損切りまでの距離の75%まで逆行したら（本数・%は設定欄のHEDGEで変更可）、保有と同じロットで反対側を建てて損失を固定します。両建した側の損切りは、元の距離の半分戻った所、利確は元の損切りと同じ位置。両建の間は新しく建てません。チャートにオレンジの「両建ライン」を表示します。
  • 建値復活：建値ストップで決済された1本を、価格がその建値まで戻ったら、同じ損切り・利確で建て直します（1本につき2回まで。建値ONのときに働きます）。

指標停止

MT5の経済指標カレンダーで、USDの重要度「高」の指標の30分前〜30分後は新しく建てません（待っている注文はそのまま、時間が過ぎたら入れます）。

稼働時間

設定欄のTIMEで、曜日と時間（日本時間）を決められます。時間外は新しく建てません。「時間外は全決済」をONにすると、時間外になったときに全部決済します。

スタンダード口座で使うとき（スタンダード対応・初期はON）

口座によって、1ロットの量が違います。FXGTのXAUUSDmなどミニ口座は1ロット＝1オンス、XM GOLD#・Vantage・HFMなどスタンダード口座は1ロット＝100オンスです。EAは口座の量に合わせてロットを計算するので、どの口座でも「損切りで 残高 × リスク%」の損失（円）は同じです。

ただしスタンダード口座では、資金が少ないと計算したロットが最小ロット（0.01＝1オンス）に届きません。たとえば100万円・リスク0.1%・SL幅$15では、0.01ロットでも1本のリスクが約0.23%になります。そのときEAは、

  • 最小ロットで入り、そのかわり同時に持てる本数を減らします。全体の上限（リスク0.1% × 最大7本 = 0.7%）は変えません。例：1本0.23%なら最大3本（為替によって2本）。
  • ADXが弱いとき（ロット半分）は、最小ロットより下げられないので、本数をさらに半分にします（例：3本 → 1本）。
  • 1本だけでも全体の上限を超えるときは、見送ります。

起動時のログ（エキスパートタブ）とパネルに「スタンダード対応: 1本 0.01ロット（リスク0.23%）・最大3本（本来7本）」のように出ます。資金がおよそ235万円以上（ADXが弱いときも7本なら約470万円以上）になると、本来どおり最大7本で動きます。ミニ・マイクロ口座ではこの機能は働かず、何も変わりません。

積み増しの本数が少なくなるので、スタンダード口座の少ない資金では、ミニ・マイクロ口座と同じ成績にはなりません（利益も落ち込みも、積み増しの分だけ小さめ）。説明書の成績はミニ口座（1ロット＝1オンス）のものです。設定のInpStdModeをfalseにすると、この機能を止められます（そのときは、最小ロットにしたリスクが設定の1.5倍以下なら最小ロットで入り、超えるなら見送ります）。
